# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils aktuelle Version.

| Version | Unterstützt |
| ------- | ----------- |
| 2.1.x   | ja          |
| < 2.1   | nein        |

## Sicherheitslücke melden

Bitte melde Sicherheitslücken nicht öffentlich als Issue. Nutze stattdessen die Funktion **„Report a vulnerability“** im Tab **Security** dieses GitHub-Repositorys.

Bitte gib dabei an:

- eine kurze Beschreibung der Lücke,
- die Schritte zum Nachstellen,
- die betroffene Version,
- mögliche Auswirkungen.

Ich bemühe mich, innerhalb von 7 Tagen zu antworten. Eine Garantie gibt es nicht, da das Projekt privat betrieben wird.

## Geltungsbereich

Gemeldet werden können Probleme im Code dieses Repositorys und im Release-Build der App.
